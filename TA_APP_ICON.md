# SVG Viewer PWA icon

Icon: Lucide `scan-eye` (v1.61.0). Shared TA icon standard: 2.0 stroke, regular scale 60%, radius 25%, monochrome foreground `#333333` and background `#E6E6E6`. Android maskable uses square full background and 54% safe-sized icon. 192/512 regular and maskable PNGs, plus SVG favicon, generated from `branding/icon-source.svg` by `.github/workflows/ta-icons.yml`.

Versioned `-v5` PNG paths supersede earlier `-v4` art to encourage existing browser installs to refresh cached app icons. No changes to share target, file handlers, theme preferences, local files or offline share inbox.

See https://github.com/teodor-andonov/ta-graphic-design-system/blob/main/APP_ICONS.md
